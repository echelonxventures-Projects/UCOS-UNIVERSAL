# UCOS Ω∞ — Universal Capability Operating System

Author: **Bipin Kumar**

A platform factory: platforms (commerce, marketplaces, mobility, media, fintech, ERP, CRM, healthcare, government and future types) are **composed from certified capabilities, context, policies and metadata**, not hand-coded.

```bash
tools/ci.sh          # everything CI runs: hash-locked toolchain, generators in sync, checker, contracts,
                     # scenarios, SLOs, self-test, proto lint, site build. Same command locally and in CI.
tools/ci.sh --fix    # regenerate generated files first
```

CI is deterministic and needs no person or AI in the loop (ADR-036): pull requests run `tools/ci.sh`, pushes to `main` are regenerated and committed by the CI bot, a nightly run catches drift, and tags (`vX.Y.Z`) publish the site and PDF as a release. See [CONTRIBUTING.md](CONTRIBUTING.md).
